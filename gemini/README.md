# Shape for Gemini CLI

Install the extension from its public repository:

```sh
gemini extensions install https://github.com/shapefs/shape-plugin
```

In Gemini CLI, run `/mcp auth shape` when prompted to authorize Shape. Complete the browser sign-in, choose your workspace and approve the capabilities you want. No API key is needed.

Ask “List the folders in my Shape workspace” to confirm the connection. You can then find project sources, save a brief, revise text and organize files. The bundled `shape-files` skill explains how to preserve source identity and Versions when making changes.

You need a Shape account and workspace. Available actions depend on your permissions, workspace limits and client support. Review or revoke the connection from Shape → Connect.
